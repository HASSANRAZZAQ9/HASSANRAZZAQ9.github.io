# MLForge — Machine Learning Tutorial Website

This is a static starter website. It requires no login system or backend.

## Run locally
Open `index.html` in a browser, or use a simple local server:
`python -m http.server 8000`

Then visit `http://localhost:8000`.

## Publish
Upload all files to any static hosting provider or your own hosting.

## Before monetization
Replace the placeholder content with your own original tutorials, add real Privacy/Terms/Contact pages, add a sitemap and robots.txt, connect Google Search Console/Analytics, and apply for an advertising platform when the site has useful original content.

## Files
- index.html — home page
- tutorial.html — tutorial template
- tutorial.js — tutorial content
- styles.css — responsive styling
- script.js — search + calculators
