Gradient Descent Explained

Understand gradient descent from mathematical intuition to Python implementation, including gradients, learning rate, cost function, and parameter updates.

1. What Is Gradient Descent?

Gradient descent is an optimization algorithm used to find parameter values that minimize a cost function.

In machine learning, we first make predictions, calculate how wrong those predictions are, and then use the gradient to decide how the model parameters should change.

The basic idea is:

  • Calculate the cost.
  • Calculate the gradient.
  • Move the parameters in the opposite direction of the gradient.
  • Repeat the process.

2. Gradient Descent Formula

For a parameter w, the update rule is:

w := w − α ∂J/∂w

For the bias:

b := b − α ∂J/∂b

Here:

  • w = model parameter
  • b = bias
  • α = learning rate
  • J = cost function
  • ∂J/∂w = gradient with respect to w

3. Why Do We Subtract the Gradient?

The gradient tells us the direction in which the cost increases. Therefore, moving in the opposite direction helps reduce the cost.

That is why the update contains:

− α × gradient

A large gradient produces a larger parameter update, while a small gradient produces a smaller update.

4. Learning Rate

The learning rate controls how large each parameter update is.

For example:

  • Very small learning rate → learning can be slow.
  • Very large learning rate → the algorithm may overshoot the minimum.
  • Suitable learning rate → the cost can gradually decrease.

A common symbol for the learning rate is:

α

5. Gradient Descent for Linear Regression

For multiple linear regression, the prediction is:

ŷ = Xw + b

The mean squared error cost function can be written as:

J(w,b) = (1 / 2m) Σ(ŷ − y)²

The gradients are:

∂J/∂w = (1/m) Xᵀ(ŷ − y)

∂J/∂b = (1/m) Σ(ŷ − y)

6. Python Implementation

import numpy as np

def predict(X, w, b):

    return np.dot(X, w) + b


def compute_cost(X, y, w, b):

    m = len(y)

    predictions = predict(X, w, b)

    error = predictions - y

    cost = (1 / (2 * m)) * np.sum(error ** 2)

    return cost

7. Gradient Descent Code

def gradient_descent(X, y, w, b, learning_rate, iterations):

    m = len(y)

    for _ in range(iterations):

        predictions = predict(X, w, b)

        error = predictions - y

        dw = (1 / m) * np.dot(X.T, error)

        db = (1 / m) * np.sum(error)

        w = w - learning_rate * dw

        b = b - learning_rate * db

    return w, b

8. The Complete Process

Gradient descent repeatedly performs the following process:

  1. Initialize weights and bias.
  2. Calculate predictions.
  3. Calculate the error.
  4. Calculate the gradients.
  5. Update weights and bias.
  6. Repeat for a number of iterations.

The objective is to find parameters that produce a lower cost and better predictions.
