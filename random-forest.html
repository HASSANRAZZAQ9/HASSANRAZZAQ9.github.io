Random Forest Explained

Understand how Random Forest combines many decision trees to make more robust predictions for classification and regression.

1. What Is Random Forest?

Random Forest is an ensemble machine learning algorithm based on multiple decision trees.

Instead of relying on one decision tree, Random Forest creates many trees and combines their predictions.

The main idea is:

  • Create many different training samples.
  • Train a decision tree on each sample.
  • Use randomness when selecting features.
  • Combine the predictions of all trees.

2. Why Use Multiple Trees?

A single decision tree can sometimes become highly specialized to its training data.

Combining many trees can reduce the effect of an individual tree's errors.

This is called an ensemble method.

3. Bootstrap Sampling

Random Forest commonly uses bootstrap samples to train individual trees.

Suppose the original training dataset contains m examples.

A bootstrap sample is created by repeatedly selecting examples from the training dataset with replacement.

Different trees therefore receive different training samples.

4. Random Feature Selection

Random Forest also introduces randomness when choosing features for tree splits.

Instead of considering every feature at every split, the algorithm considers a randomly selected subset of features.

This makes the trees less dependent on the same features and helps create diversity among the trees.

5. Random Forest Classification

For classification, each tree produces a class prediction.

The final prediction is commonly determined by majority voting.

For example, suppose five trees predict:

  • Tree 1 → Class 1
  • Tree 2 → Class 1
  • Tree 3 → Class 0
  • Tree 4 → Class 1
  • Tree 5 → Class 0

Class 1 receives three votes, while Class 0 receives two votes. The ensemble therefore predicts Class 1.

6. Random Forest Regression

For regression, the predictions from the individual trees can be combined using their average.

For T trees:

ŷ = (1/T) Σ ŷt

where each ŷt is the prediction from one tree.

7. Important Hyperparameters

  • n_estimators → number of trees.
  • max_depth → maximum depth of each tree.
  • min_samples_split → minimum samples required to split.
  • min_samples_leaf → minimum samples in a leaf.
  • max_features → number of features considered for splits.

8. Python Classification

from sklearn.ensemble import RandomForestClassifier

model = RandomForestClassifier(
    n_estimators=100,
    random_state=42
)

model.fit(X_train, y_train)

predictions = model.predict(X_test)

9. Python Regression

from sklearn.ensemble import RandomForestRegressor

model = RandomForestRegressor(
    n_estimators=100,
    random_state=42
)

model.fit(X_train, y_train)

predictions = model.predict(X_test)

10. Random Forest Workflow

  1. Prepare the dataset.
  2. Split the data into training and testing sets.
  3. Create bootstrap samples.
  4. Train multiple decision trees.
  5. Use random feature subsets during tree construction.
  6. Collect predictions from all trees.
  7. Combine the predictions.
  8. Evaluate the final model.

11. Next Steps

After Random Forest, learn boosting algorithms such as XGBoost. Boosting takes a different approach by building models sequentially to improve previous predictions.
