Multiple Linear Regression From Scratch

Learn how multiple linear regression works from mathematical intuition to Python implementation.

1. Intuition

Multiple linear regression predicts a numerical value using multiple input features.

The basic model is:

ŷ = b₀ + b₁x₁ + b₂x₂ + ... + bₙxₙ

For example, we could predict house price using:

  • House size
  • Number of bedrooms
  • House age

2. Mathematics

The prediction is:

ŷ = Xw + b

The mean squared error cost function is:

J(w,b) = (1 / 2m) Σ(ŷ - y)²

Gradient descent updates the parameters repeatedly to reduce the cost.

w := w − α ∂J/∂w

b := b − α ∂J/∂b

3. Python

import numpy as np

def predict(X, w, b):
    return np.dot(X, w) + b

def compute_cost(X, y, w, b):

    m = len(y)

    predictions = predict(X, w, b)

    error = predictions - y

    cost = (1 / (2 * m)) * np.sum(error ** 2)

    return cost

4. Gradient Descent

def gradient_descent(X, y, w, b, learning_rate, iterations):

    m = len(y)

    for _ in range(iterations):

        predictions = predict(X, w, b)

        error = predictions - y

        dw = (1 / m) * np.dot(X.T, error)

        db = (1 / m) * np.sum(error)

        w = w - learning_rate * dw

        b = b - learning_rate * db

    return w, b
