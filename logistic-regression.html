Logistic Regression With Python

Learn logistic regression from mathematical intuition to Python, including the sigmoid function, decision boundary, log loss, and gradient descent.

1. What Is Logistic Regression?

Logistic regression is a supervised machine learning algorithm used mainly for binary classification.

Instead of predicting a continuous numerical value, the model predicts the probability that an example belongs to a particular class.

For example, we could predict whether a student will pass or fail based on study hours.

  • 0 → Fail
  • 1 → Pass

2. Linear Model

Logistic regression first calculates a linear combination of the input features:

z = w₁x₁ + w₂x₂ + ... + wₙxₙ + b

Or using vectors:

z = Xw + b

The value of z can be any real number.

3. Sigmoid Function

The linear model output is passed through the sigmoid function.

f(z) = 1 / (1 + e⁻ᶻ)

The sigmoid function converts any value into a number between 0 and 1.

  • z → large positive value → probability approaches 1
  • z = 0 → probability = 0.5
  • z → large negative value → probability approaches 0

Therefore, the model's prediction can be interpreted as a probability.

4. Classification Threshold

A common threshold is 0.5.

If:

f(z) ≥ 0.5 → class 1

and:

f(z) < 0.5 → class 0

For example, if the model predicts 0.82, the predicted class would normally be 1 when using a 0.5 threshold.

5. Decision Boundary

The decision boundary separates the two predicted classes.

With a threshold of 0.5:

f(z) = 0.5

The sigmoid function equals 0.5 when:

z = 0

Therefore, the decision boundary is:

w₁x₁ + w₂x₂ + ... + wₙxₙ + b = 0

6. Logistic Regression Cost Function

Mean squared error is generally not used as the standard cost function for logistic regression.

Instead, logistic regression uses log loss, also called binary cross-entropy loss.

For one training example:

L(f(x), y) = −y log(f(x)) − (1 − y) log(1 − f(x))

For the complete training set:

J(w,b) = −(1/m) Σ[ y log(f(x)) + (1−y) log(1−f(x)) ]

7. Why Log Loss?

Log loss strongly penalizes confident incorrect predictions.

For example, predicting a probability close to 1 for the wrong class produces a large loss.

This encourages the model to produce probabilities that better match the actual labels.

8. Gradient Descent

The parameters are learned by minimizing the cost function.

The update for a parameter is:

w := w − α ∂J/∂w

The bias is updated using:

b := b − α ∂J/∂b

For logistic regression, the gradient can be written as:

∂J/∂w = (1/m) Xᵀ(f(X) − y)

and:

∂J/∂b = (1/m) Σ(f(x) − y)

9. Python Implementation

import numpy as np


def sigmoid(z):

    return 1 / (1 + np.exp(-z))


def predict_probability(X, w, b):

    z = np.dot(X, w) + b

    return sigmoid(z)

10. Compute the Cost

def compute_cost(X, y, w, b):

    m = len(y)

    probabilities = predict_probability(X, w, b)

    cost = -(1 / m) * np.sum(
        y * np.log(probabilities) +
        (1 - y) * np.log(1 - probabilities)
    )

    return cost

11. Gradient Descent

def gradient_descent(X, y, w, b, learning_rate, iterations):

    m = len(y)

    for _ in range(iterations):

        probabilities = predict_probability(X, w, b)

        error = probabilities - y

        dw = (1 / m) * np.dot(X.T, error)

        db = (1 / m) * np.sum(error)

        w = w - learning_rate * dw

        b = b - learning_rate * db

    return w, b

12. Making Predictions

def predict(X, w, b):

    probabilities = predict_probability(X, w, b)

    predictions = (probabilities >= 0.5).astype(int)

    return predictions

13. Complete Workflow

  1. Load the dataset.
  2. Separate features X and target y.
  3. Initialize weights and bias.
  4. Calculate z.
  5. Apply the sigmoid function.
  6. Calculate log loss.
  7. Calculate gradients.
  8. Update weights and bias using gradient descent.
  9. Repeat the process.
  10. Use the trained model to make predictions.
