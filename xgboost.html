BOOSTING

XGBoost Regression

Learn the fundamentals of XGBoost regression, including gradient boosting, sequential trees, loss minimization, learning rate, regularization, and Python implementation.

1. What Is XGBoost?

XGBoost is a gradient boosting algorithm based on decision trees.

Instead of building all trees independently, boosting builds trees sequentially. Each new tree is trained to improve the existing model.

The basic idea is:

  • Start with an initial prediction.
  • Measure the model's errors.
  • Build a new tree that improves those errors.
  • Add the new tree to the existing model.
  • Repeat the process.

2. Additive Model

A boosting model can be represented as a sum of tree predictions.

ŷ(x) = Σ fk(x)

where each fk represents a decision tree.

The model gradually becomes more accurate as additional trees are added.

3. Gradient Boosting

Gradient boosting uses information from the loss function to determine how the next tree should improve the current model.

Conceptually, the algorithm repeatedly moves in a direction that reduces the model's loss.

This is related to the same optimization idea behind gradient descent: the goal is to minimize a cost or loss function.

4. Learning Rate

The learning rate controls how much each new tree contributes to the final model.

A simplified update can be represented as:

Fnew(x) = Fold(x) + α f(x)

where α is the learning rate.

A smaller learning rate usually means that more trees may be needed to build the model.

5. Regularization

XGBoost includes mechanisms that can control model complexity.

Regularization helps reduce the risk of creating overly complex trees and overfitting the training data.

Important parameters include:

  • max_depth → controls tree depth.
  • min_child_weight → controls minimum child weight.
  • subsample → controls the fraction of training samples used.
  • colsample_bytree → controls feature sampling.
  • reg_alpha → L1 regularization.
  • reg_lambda → L2 regularization.

6. Important Hyperparameters

  • n_estimators → number of boosting rounds.
  • learning_rate → contribution of each tree.
  • max_depth → maximum tree depth.
  • subsample → fraction of samples used.
  • colsample_bytree → fraction of features used.

7. Python Implementation

from xgboost import XGBRegressor

model = XGBRegressor(
    n_estimators=100,
    learning_rate=0.05,
    max_depth=3,
    random_state=42
)

model.fit(X_train, y_train)

predictions = model.predict(X_test)

8. Evaluating the Model

from sklearn.metrics import mean_absolute_error
from sklearn.metrics import mean_squared_error
import numpy as np

mae = mean_absolute_error(y_test, predictions)

rmse = np.sqrt(
    mean_squared_error(y_test, predictions)
)

print("MAE:", mae)
print("RMSE:", rmse)

9. XGBoost Workflow

  1. Load the dataset.
  2. Prepare the features and target.
  3. Split the dataset into training and testing data.
  4. Create the XGBoost model.
  5. Train the model.
  6. Build trees sequentially.
  7. Generate predictions.
  8. Evaluate the predictions.
  9. Tune hyperparameters when necessary.

10. Next Steps

After learning XGBoost, an important next topic is regularization. Regularization is used to control model complexity and reduce overfitting.
